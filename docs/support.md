# Support

- **Something isn't working?** Check [Troubleshooting](troubleshooting.md) first.
- **Report a problem or ask a question:** open an issue on
  [GitHub](https://github.com/morehavoc/spiel/issues). On the Mac, Help → **Send
  Diagnostics** makes a zip you can attach; it contains no dictated text.
- **Refunds:** within 14 days of purchase, through Gumroad.
