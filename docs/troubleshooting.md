# Troubleshooting

**The shortcut does nothing.** Another app may own that key combination. Spiel shows a
warning icon in the menu bar and the reason in the menu; pick another key in Settings →
General → Shortcuts, or use **Use F5 Instead** from the menu.

**Text doesn't appear in the app I'm typing in.** Check System Settings → Privacy &
Security → Accessibility and make sure Spiel is on. If it was just updated, turn it off and
on again. Your last dictation is always in **History** and **Copy Last Dictation**.

**Nothing is typed in a password field.** Intentional. When macOS Secure Input is on, Spiel
won't type and doesn't keep what you said.

**It hears the wrong word for a name or term.** Add it in Settings → **Vocabulary**.

**The Listen meter barely moves.** Check the input in Settings → Microphone and your Mac's
input volume. The meter adjusts to quiet mics; if it stays flat, the mic may be the wrong one.

**The model download failed.** Check your connection and press **Retry** in the setup
window (Help → Setup…).

**My Shortcut runs but gets nothing.** Turn on input for the Shortcut: see
[Run a Shortcut when Listen stops](shortcuts.md#1-make-the-shortcut-accept-input).

Still stuck? See [Support](support.md).
