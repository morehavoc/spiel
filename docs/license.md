# Licensing and activation

This page is about the Mac app from Gumroad. A build you compile yourself from the source
has no license check. The iPhone app is free while it is in testing.

## The trial

- Spiel works fully for 14 days from the first time you open it.
- The menu shows how many days are left.
- When the trial ends, starting Dictation or Listen opens the **License** window instead.
  Your transcripts, History and Vocabulary stay where they are. The `spiel` command stops
  transcribing and exits with code 5.

## Activate a key

1. Buy Spiel on [Gumroad](https://morehavoc.gumroad.com/l/spiel). The key is in your receipt
   email, and in your Gumroad library if you have a Gumroad account.
2. In Spiel's menu, choose **Enter License Key…**.
3. Paste the key and click **Activate**. This needs an internet connection.

Once activated, the menu item becomes **License…**, where you can see or change the key.

## Two Macs per key

- Each activation uses one of the key's 2 seats. Activating on a new Mac, or on the same Mac
  after deleting Spiel's settings, uses a seat.
- Entering the same key again on a Mac where it is already active does not use another seat.
- Removing Spiel from a Mac does not give the seat back. If you need a seat freed (a new or
  replaced Mac, for example), ask through [Support](support.md). Support issues are public,
  so do not post your key or your receipt there.

## If activation fails

The License window says why:

- **"This key is already used on 2 Macs."** Both seats are in use. Ask for a reset through
  [Support](support.md).
- **"That key is not valid for Spiel."** Check that you copied the whole key from the receipt,
  with no extra characters.
- **"That key is for a different product."** It is a key for something else you bought on
  Gumroad.
- **"Could not reach Gumroad. Try again."** Check your internet connection.
- **"This purchase was refunded"**, **"charged back"** or **"This key has been disabled."**
  The key no longer works.

## The weekly check

About once a week, Spiel checks the key with Gumroad. It sends only the key and Spiel's
product ID.

- **Offline is fine.** If Spiel can't reach Gumroad, nothing changes; it tries again a day
  later.
- A key is turned off only if Gumroad reports it refunded, charged back or disabled on two
  checks in a row. A session already running is never cut off.

## Refunds

Within 14 days of purchase, reply to your Gumroad receipt to ask for a refund. A refunded
key stops working after two weekly checks.
